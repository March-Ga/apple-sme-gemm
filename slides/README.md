# SME and Accelerate on Apple M4 Pro

A 15-slide English teaching deck covering the current implementation:

- [PDF](sme-on-apple-m4-pro.pdf)
- [Editable PowerPoint](sme-on-apple-m4-pro.pptx), including speaker notes
- [Overview](overview.png)
- [Detailed speaker notes and references](speaker_notes.md)

Slides 1–4 introduce SME, outer products, vectors and ZA. Slides 5–10 explain
the final data paths, packing, 16×64 kernel, blocking and edge handling.
Slides 11–15 cover the measurement protocol, throughput/speedup comparison,
selected results, reproduction and primary sources. There are no historical
or experimental implementation comparisons in this deck.

Text and diagrams are editable PowerPoint objects. The performance chart is
an image generated by the same `plot.py` function used for ordinary benchmark
runs; its data and SVG version live in [`examples/m4-pro/`](../examples/m4-pro/).
The PDF has selectable text and vector diagrams.

## Rebuild

From the repository root:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r slides/requirements.txt
.venv/bin/python slides/build_slides.py
```

The generator reads the existing full-suite data and current source files;
it never compiles or runs GEMM. It validates throughput, paired speedups and
IQR against raw jobs, source hashes, text widths, boundaries and collisions.
`data_manifest.json` records the inputs. The included deck was rendered and
visually inspected.

To rebuild the optional overview as well:

```sh
.venv/bin/python -m pip install PyMuPDF==2.1
.venv/bin/python slides/build_slides.py --preview
```

Another complete eight-size run can be selected without executing it:

```sh
.venv/bin/python slides/build_slides.py --results results/run1 --output results/run1/slides
```

Arial is used on macOS; PDF generation falls back to Matplotlib's DejaVu fonts
when unavailable. PowerPoint may substitute fonts according to the viewer.
The notes cite Arm ACLE, the University Jena Hello SME microbenchmarks, and
Apple's Accelerate/BLAS documentation. All plotted results are local measurements.
